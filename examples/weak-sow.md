# Statement of Work: Order Portal

Prepared by Lanternfield Software for Brightmoor Bakery Supply. Questions go to orders@brightmoor.example.com.

## 1. Goals

Brightmoor wants a modern online order portal, so that the cafes it supplies can order stock without phoning the office.

## 2. Scope

Lanternfield will design, build and launch the order portal and an admin area for the office team.

- Customer accounts and sign-in
- Product catalogue with prices for each customer
- Order history and reorder, etc.

## 3. Deliverables

- A fast, user-friendly web portal that works on phones.
- An admin area with reports as needed.
- A link to the accounting system, if possible.
- Documentation and so on.

The portal shows a "Fast reorder" button on the home page. The admin area keeps this setting:

```text
reorder-mode: fast
```

## 4. Acceptance

The client will test the portal and accept it when it is ready.

- The portal is easy to use for cafe staff.
- Pages load quickly.
- Orders reach the accounting system.
- The admin area passes the "Month end" test script.
